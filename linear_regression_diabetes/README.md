## 🎯 Objective

Predict the **progression of diabetes** one year after baseline using clinical measurements of 442 patients.

---

## 📚 Workflow

1. Load & explore the diabetes dataset
2. Convert to a pandas DataFrame
3. Train-test split (80/20)
4. Train a Linear Regression model
5. Evaluate performance (MSE, RMSE, R²)
6. Compare to a baseline (mean predictor)
7. Visualize predictions and residuals

---

## 📊 Evaluation Metrics

| Metric | Meaning |
|--------|---------|
| **MSE** | Mean Squared Error |
| **RMSE** | Root Mean Squared Error |
| **R² Score** | Proportion of explained variance |
